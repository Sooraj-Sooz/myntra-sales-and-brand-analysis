# 👖 Myntra Jeans Analytics Dashboard

## 📌 Project Overview
An end-to-end retail analytics project analyzing Myntra jeans data using:

- 🐍 Python
- 🗄 SQL
- 📑 Excel
- 📊 Power BI
- 📈 Plotly

The project focuses on uncovering business insights related to:

✅ Brand Performance  
✅ Customer Ratings  
✅ Pricing Strategies  
✅ Discount Analysis  
✅ Product Segmentation  
✅ Customer Engagement  

Interactive dashboards and visualizations were created to support data-driven decision making in the fashion retail industry.

# 🔍 Key Findings

✅ Mid-range products dominate the marketplace.

✅ Most products maintain ratings above 4.0.

✅ Roadster has the highest customer engagement.

✅ United Colors Of Benetton offers the highest discounts.

✅ Premium brands maintain higher pricing and strong customer trust.
